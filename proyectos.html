Mis proyectos

Una selección de trabajos relacionados con mis estudios y mi aprendizaje en DAM.

Portfolio personal

Diseño de un sitio web personal compuesto por tres páginas: inicio, proyectos y contacto. Se utilizan etiquetas semánticas HTML5 y una estructura de navegación compartida.

Objetivo: presentar información personal de forma clara y permitir la navegación entre las diferentes páginas del sitio web.

Tecnología: HTML5.

Base de datos de una biblioteca

Diseño de un modelo conceptual mediante un diagrama entidad-relación para gestionar libros, autores, temas, editoriales, socios y recibos.

Objetivo: organizar la información y representar las relaciones entre las entidades de una biblioteca.

Área: Bases de datos.

Integración de pedidos

Ejercicio de estructuración de un pedido comercial en XML, separando los datos generales de la información logística mediante elementos organizados.

Objetivo: practicar la creación de documentos XML para representar e intercambiar información en un proceso de integración de pedidos.

Tecnología: XML.
